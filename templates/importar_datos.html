Instrucciones
📋 Formato de archivo CSV esperado:

El archivo debe tener las siguientes columnas:

  • Fecha_Compra - Fecha en formato YYYY-MM-DD
  • Precio_Compra - Precio unitario del activo
  • Cantidad_Compra - Número de unidades
  • Comision_Broker - Comisión del broker (opcional)
  • Precio_Dolar_MEP_Compra - Precio dólar MEP
  • Nombre_Broker - Nombre del broker
  • Nombre_Comitente - Nombre del comitente
  • Nombre_Ticker - Código del ticker
  • Descripcion_Ticker - Descripción del ticker
  • Nombre_Instrumento - Tipo de instrumento
Tip: Si ya tienes un archivo con movimientos de cuenta corriente, puedes usar el botón "Cargar Datos Reales Procesados" que ya procesó automáticamente tus archivos CSV.
