Información Importante
  • Los reportes se generan con la información más actualizada de la base de datos
  • Los nombres de archivo incluyen timestamp para evitar confusión entre versiones
  • Los filtros seleccionados se aplicarán automáticamente a los reportes
  • Los reportes Excel incluyen múltiples hojas con análisis detallado
  • Los PDFs tienen formato profesional adecuado para presentaciones ejecutivas
Ejemplos de Uso de APIs
curl Examples:
# CSV de activos con filtros
curl -X GET "http://localhost:5000/api/reports/activos-csv?Id_Broker=1&Activo_Estado=EN_CARTERA" \
  -H "Accept: text/csv" \
  --output activos_filtrados.csv

# Excel completo
curl -X GET "http://localhost:5000/api/reports/activos-excel" \
  -H "Accept: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet" \
  --output reporte_completo.xlsx

# PDF ejecutivo
curl -X GET "http://localhost:5000/api/reports/ejecutivo-pdf" \
  -H "Accept: application/pdf" \
  --output reporte_ejecutivo.pdf

# API de métricas en JSON
curl -X GET "http://localhost:5000/api/dashboard/summary" \
  -H "Accept: application/json"
JavaScript/jQuery Examples:
// Descargar CSV via JavaScript
function descargarCSV() {
    const filtros = {
        Id_Broker: $('#filtroBroker').val(),
        Id_Ticker: $('#filtroTicker').val(),
        Activo_Estado: $('#filtroEstado').val()
    };
    
    const params = new URLSearchParams(filtros);
    window.open(`/api/reports/activos-csv?${params}`, '_blank');
}

// Obtener métricas en JSON
async function obtenerMetricas() {
    try {
        const response = await fetch('/api/dashboard/summary');
        const data = await response.json();
        console.log('Métricas:', data);
    } catch (error) {
        console.error('Error:', error);
    }
}
