APIs Avanzadas Disponibles
APIs Métricas Institucionales:
  • GET /api/metrics/tir/{id} - TIR completa
  • GET /api/metrics/beta/{id} - Beta del activo
  • GET /api/metrics/alpha/{id} - Alpha del activo
APIs Análisis de Riesgo:
  • GET /api/advanced/var/{id} - Value at Risk
  • GET /api/advanced/monte-carlo/{id} - Análisis Monte Carlo
  • GET /api/advanced/stress-testing - Stress Testing
  • GET /api/advanced/esg/{id} - Métricas ESG
APIs Análisis Avanzado:
  • GET /api/metrics/correlation-matrix - Matriz correlación
  • GET /api/metrics/diversification - Diversificación
  • GET /api/advanced/portfolio-var - VaR de Cartera
  • GET /api/advanced/summary - Resumen completo
