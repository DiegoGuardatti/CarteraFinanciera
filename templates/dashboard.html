APIs Disponibles para Testing
APIs de Métricas:
  • GET /api/metrics/portfolio - ROI de cartera completa
  • GET /api/metrics/roi/{id} - ROI de activo específico
  • GET /api/metrics/sharpe/{id} - Sharpe Ratio
  • GET /api/metrics/var/{id} - Value at Risk
  • GET /api/metrics/max-drawdown/{id} - Maximum Drawdown
APIs de Análisis:
  • GET /api/metrics/top-performers - Mejores performers
  • GET /api/metrics/bottom-performers - Peores performers
  • GET /api/metrics/performance-tickers - Performance por ticker
  • GET /api/dashboard/summary - Resumen ejecutivo completo
